# ClassroomToolkit

[![Release](https://img.shields.io/github/v/release/sciman-top/ClassroomToolkit)](https://github.com/sciman-top/ClassroomToolkit/releases/latest)
[![.NET](https://img.shields.io/badge/.NET-10.0-512BD4?logo=dotnet)](https://dotnet.microsoft.com/)
[![Platform](https://img.shields.io/badge/Platform-Windows-0078D6?logo=windows)](https://www.microsoft.com/windows)
[![License](https://img.shields.io/badge/License-MIT-green)](./LICENSE)

Free & open-source classroom toolkit for Windows school PCs: random roll call, timers, screen annotation & whiteboard, image/PDF presenting, and PowerPoint / WPS slideshow control — one app for teachers.

The full documentation is maintained in Chinese only:

- [README (中文)](./README.md) — overview, download & install
- [教师使用指南](./使用指南.md) — teacher's user guide
- Releases: <https://github.com/sciman-top/ClassroomToolkit/releases/latest>

Requirements: Windows 10 / 11. MIT licensed.
