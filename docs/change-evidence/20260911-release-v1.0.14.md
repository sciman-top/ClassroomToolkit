### 2. 依赖服务更新（7a512c3）

- 必要性：.NET 9 月服务补丁（10.0.12）与 Test SDK 18.10.0 发布后，stable outdated 未豁免项触发 full 门禁红（`FailOnStableOutdated`）。

### 3. analyzer 欠账清偿（3afd60c）

- 依赖升级后 `analyzer-latest-all` 暴露 2 处新增诊断（来自 09-10 冲突修复批，未及 full 门禁）：

  - `WpsHookOrchestrator.TryStartSafeAsync` CA2007：补 `SuppressMessage` 并注明理由——调用方需回 UI 线程安装 LL WPS 钩子，故意捕获上下文（与调用点既有注释一致）。
- 回归验证：构建 0 警 0 错；定向测试 37/37；analyzer 计数回到基线 19。

### 4. 放映批注快照兜底修复（a405d37，AI 冒烟发现）

- 现象：全新安装默认设置（`ink_record_enabled=false`，自仓库初始化即默认）下，放映批注退出即静默丢失——`PresentationInkExitSnapshotPolicy.ShouldCapture` 的 `strokeCount > 0` 恒假（记录关闭时笔画不进向量表），P1-3 修复的快照兜底在默认配置下是死路径。AI 实机冒烟复现：放映书写→退出→无任何 PNG 落盘。
- 修复：判据改为只看位图表面 `hasDrawing`（快照编码本不依赖向量表）；策略测试更新锁定该语义（6/6）。
- 修复后复现验证：同流程（全新安装默认设置 + 放映书写 + 退出）→ `data/Ink/20260911/presentation/presentation_20260911_093552603.png` 成功落盘，内容即所绘墨迹。
- 回滚：revert 该提交；行为回到"默认设置下批注不落盘"。
